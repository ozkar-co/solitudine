SOLITUDINE — BETA DEV (PC)
==========================

Esta es una build temporal de testing. No es la versión de consola.

Requisitos
----------
- Windows 10/11 de 64 bits, o Linux x86_64.
- No hace falta instalar Python ni pygame.

Cómo ejecutar
-------------
Windows:  SolitudineBeta.exe      -> 640x480 (1x)
Linux:    ./SolitudineBeta        -> 640x480 (1x)

Abre en modo dev y no tiene menú de opciones.

Esta build no está firmada. En Windows puede aparecer SmartScreen:
elegir "Más información" -> "Ejecutar de todas formas".
En Linux, si no arranca: chmod +x SolitudineBeta

Controles de teclado
--------------------
E = A        Esc = B       Q = recursos    Tab = construir
J = A        K = B         T = acelerar tiempo (dev)
1 = zoom in  2 = zoom out  3 = minimapa   4 = libre
WASD = cursor              Flechas = cámara
Enter = START              Bksp = SELECT
Bksp + Enter = salir
Pausa (Enter) -> Salir

También acepta mando si el sistema lo detecta.

Guardado y log
--------------
- Guardado:      saves/save.json
- Log de la run: solitudine-beta.log

Quedan junto al ejecutable. Los saves son de beta y no migran entre
versiones. Si el juego falla, enviá el log junto con una descripción breve
de lo que estabas haciendo.

Gracias por probar.
